# Example: rebuild a slop landing page

## Input

User: "Make a landing page for my note app. It is a small
tool: you write notes in the browser, they are saved locally,
nothing is uploaded. I have no users yet."

## Bad output (do not do this)

A hero with "🚀 Unlock the ultimate productivity
revolution!" and "Transform your workflow by 10,000% with
AI-powered next-level notes!", three gradient cards
("Blazing fast", "Super secure", "Loved by millions"),
a chart claiming "98.7% happier users", and five purple
"Get started" buttons.

Why it is bad: every number is invented (there are no
users yet), the copy says nothing about what the tool
does, and five identical buttons compete with each other.

## Good output

**Screen, top to bottom:**

1. Heading: "Notes that open where you left off."
2. One line: "Write a note, close the tab, come back
   tomorrow — it is still here. Nothing is uploaded."
3. Primary button: "Write your first note"
4. Quiet link under it: "See how it works (1 minute)"
5. Below, one short section, "How it works", with three
   plain steps: "1. Write. 2. Close the tab. 3. Come back —
   your note is still here."
6. Nothing else. No chart, no testimonials, no statistics.

**Why each element passes the purpose test:**

- Heading + one line: tells the user what the tool does
  and what makes it different (local, nothing uploaded).
- One primary button: the user's task is to start writing.
- "See how it works": for the user who is not ready yet.
- "How it works": answers the only question left — "what
  happens to my notes?" — in three plain steps.
- No chart or testimonials: there are no users yet, so
  there is nothing honest to show. The empty space is
  honest; a fake chart would be a lie.
